# 留数实验室

一个无需构建工具的中文交互网页，介绍留数的定义、留数定理、三种常见计算方法和三道分步例题。

## 本地运行

使用 Node.js 启动本地静态服务：

```powershell
node serve.mjs
```

随后访问 `http://127.0.0.1:8000`。

## 内容核对

- 洛朗展开中 `(z−z₀)⁻¹` 的系数是留数。
- 围道实验使用 `1/[z(z−1)] = −1/z + 1/(z−1)`，因此两极点的留数分别为 `−1` 与 `+1`。
- 半径 `r=1` 时围道经过极点，通常的围道积分未定义。
- 三道例题分别给出留数 `−1`、`1/2−i`、`e`。

网页是纯静态资源，无用户数据与后端依赖。数学计算旁的“数学旁白”用于帮助理解；`app.js` 中也给关键判断写了注释。
